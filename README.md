## Selected projects

### Sign Language Recognition

A 100-class video classification pipeline using Python, PyTorch, and OpenCV, covering frame sampling, preprocessing, augmentation, training, and inference.

- Experimented with pretrained CNN backbones and Transformer-based temporal modeling.
- Investigated duplicate samples, validation leakage, and class imbalance.
- Achieved **74.57% Macro-F1** on the private test set of the 2025 OLP AI task, used for practice.

### Large-Scale N-Puzzle Solver

A university group project in C++, exploring search strategies and large-board optimization.

- Designed a macro-based strategy using alternating row/column operations with BFS fallback.
- Compared BFS, IDA*, and hybrid search approaches.
- Benchmarked an AI-optimized implementation on **1000 × 1000 boards**: **21/30 solved** within **10 seconds / 1 GB RAM**; successful runs averaged **9.00 seconds**.
- Directed AI-assisted implementation and iterative optimization of the strategy.

### Local Coding Agent

A personal experiment with Python and Ollama, connecting locally generated code to C++ compilation, execution, and automated test feedback.
